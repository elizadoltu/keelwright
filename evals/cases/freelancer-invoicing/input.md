# Project idea: invoicing for freelancers

A web app where freelancers create clients, send invoices and see which ones are paid.

- Public pages: a landing page, pricing and a few help articles. These must rank in search.
- After signing up, a freelancer manages clients, creates invoices from a template, sends them by email as a PDF link, and marks them paid.
- A dashboard shows unpaid and overdue totals per month.
- Each freelancer only ever sees their own data.
- About 500 users in the first year; built by a team of two TypeScript developers.

Out of scope for now: online card payments, multiple users per account, a mobile app.
