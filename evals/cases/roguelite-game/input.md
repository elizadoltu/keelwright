# Project idea: Lantern Deep

A small 2D roguelite for PC, sold on Steam: the player explores procedurally generated caves with a lantern whose oil runs out, collects relics and tries to get deeper each run. Runs last about 15 minutes. Pixel art, made by a friend; music bought from a licensed pack.

I'm a solo developer. I know some Python and have never shipped a game. I'd like to avoid paying engine royalties. A web demo for itch.io would be nice later.

Progress between runs (unlocked relics) is saved on the player's computer. No online features.
