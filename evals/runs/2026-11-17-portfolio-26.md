## Findings

| # | Finding | Fix |
|---|---|---|
| 1 | **CI failed on the first push.** `check` ran ESLint before Astro had generated `.astro/` (gitignored), so `astro:content` types didn't resolve on a fresh checkout. Fixed by hand in the project (`npm run sync` first). | `reference/web-scaffold.md`: `check` starts with the framework's type generation; `scaffoldcheck` reports an Astro `check` without `astro sync` |
| 2 | **`CLAUDE.md` names folders a clone doesn't have.** The skeleton created empty `src/components/atoms/` and `molecules/`; git doesn't keep empty folders, so `generatecheck` passed locally and fails after a clone. | Web scaffold: `.gitkeep` in empty structure folders; `generatecheck` reports an empty folder named in the setup |
| 3 | **The token script doesn't support a theme toggle.** Dark colours were emitted only under `prefers-color-scheme`; the design's Dark / Light button would have needed hand-written CSS outside the tokens. | `tokens.css` also emits `:root[data-theme='dark']`, and the system setting yields to `data-theme='light'` |
| 4 | **Step times not measured for `prd`, `features`, `generate`:** the steps wrote their files first and ran `STATE start` just before `STATE complete`. | `commands/kickoff.md`: start before any work; `STATE complete` warns and the report shows "not measured" |
| 5 | **The edit metric counted the approval's own `status:` change** as one added and one removed line in every document, hiding the real signal. | The front-matter `status:` line is left out of the comparison |
| 6 | **gitleaks failed with a 403 on every pull request.** The workflow restricted `permissions` to `contents: read`; the gitleaks action lists a PR's commits through the API, which needs `pull-requests: read`. Fixed by hand in the project's first PR. | `git-hooks` pack and `reference/toolchains.md`: grant `pull-requests: read` and turn off PR comments; `scaffoldcheck` reports gitleaks under restricted permissions without it |

Noted, no change:

- `eslint-plugin-jsx-a11y` doesn't support ESLint 10 yet; the scaffold used the maintained fork `eslint-plugin-jsx-a11y-x`. The Astro pack should name it at the next refresh.
- Astro 7 keeps one background preview per project; another preview held port 4321, so Playwright uses `--port 4399 --ignore-lock`. Watch for it in the next web run.
- Documents finish just under their word limits after 3–4 `doccheck` failures (PRD, visual identity). The limits work; the cost is extra rewriting passes.
- Cost wasn't recorded: the run used the owner's subscription, and metrics don't track cost.
